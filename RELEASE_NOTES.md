### What's new

- **Discover**: a curated selection of complete, high-quality cursor sets from rw-designer — no duplicates, no old
  pixel art. Rest on a card to try it with your own pointer.
- **Round glow**: a soft halo behind the cursor, with colour, brightness, size, softness and position controls.
  The outline-hugging glow is still available.
- **Exact sizes**: each cursor file now holds exactly the size Windows uses, so no shape can show up at a different
  size than the others. After applying, CURSORA measures what Windows draws and corrects it if needed.
- **Faster studio**: sliders stay smooth even on heavy packs.
- **In-app updates**: a small pill in the title bar when a new version is available.
- Smaller installer.
